OLX Telegram Bot

Автоматизация публикаций объявлений о продаже квартир в Ташкенте.

Как работает проект

1. Находит объявления о продаже квартир на OLX.
2. Отбирает объявления от собственников, насколько это возможно проверить.
3. Подготавливает публикацию по шаблону с фотографиями и ссылкой на оригинал.
4. Отправляет публикацию на проверку перед размещением в Telegram-канале.

Настройки

• Город: Ташкент
• Тип сделки: продажа
• Публикация: только после одобрения
• Повторные объявления: не публиковать повторно
